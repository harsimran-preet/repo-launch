# Contributing to <project>

Thanks for helping! Small fixes are as welcome as big features.

## Quick start

1. Fork and clone: `git clone https://github.com/<you>/<repo> && cd <repo>`
2. Install: `<one install command>`
3. Run the tests: `<test command>`

## Making a change

- Look for issues labelled [`good first issue`](https://github.com/<owner>/<repo>/labels/good%20first%20issue) if you're new.
- For anything bigger than a bug fix, open an issue or a [Discussion](https://github.com/<owner>/<repo>/discussions) first so we can agree on the approach.
- Create a branch, keep the change focused, and add a test when you fix a bug.
- Run `<lint command>` and `<test command>` before you push.

## Opening a pull request

- Describe what changed and why; link the issue (`Fixes #123`).
- CI must pass. A maintainer usually replies within a day.

## Code of conduct

Be kind and assume good intent.
