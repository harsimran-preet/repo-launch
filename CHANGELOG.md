## [0.1.0] - 2026-11-04

### Added

- `/repo-launch` skill: audit, fix, confirm, verify workflow for the 16-step open-source launch checklist.
- `scripts/audit.py`: read-only audit of all 16 items using local files, git history and the GitHub CLI.
- `references/checklist.md`: why, pass criteria and fix recipe for every item.
- CONTRIBUTING and GitHub issue/PR templates in `assets/`.
- Unit tests for the audit heuristics.
